# 🌌 MathGalaxy

**پروژه خفن خفن خفن پایتونی برای تولید هنر ریاضی و فراکتال‌های کیهانی**

یک ابزار فوق‌العاده زیبا و قدرتمند برای ساختن تصاویر فراکتالی، الگوهای ریاضی و کهکشان‌های عددی با پایتون.

ساخته شده با ❤️ برای امیرحسین بخشی — برنامه‌نویس فول‌استک، عاشق ریاضی و رویای مهاجرت به آمریکا.

---

## ✨ ویژگی‌ها

- تولید **Mandelbrot Set** با زوم فوق‌العاده و رنگ‌بندی کیهانی
- تولید **Julia Set** با پارامترهای قابل تنظیم
- الگوهای **Sierpinski** و **Barnsley Fern**
- خروجی تصویر با کیفیت بالا (PNG)
- انیمیشن زوم (GIF)
- رابط کاربری زیبا در ترمینال با رنگ‌ها
- کاملاً ماژولار و قابل توسعه

---

## 🚀 نصب و اجرا

```bash
git clone https://github.com/Amirhosseinbakhshi2011/MathGalaxy.git
cd MathGalaxy
pip install -r requirements.txt
python main.py
```

---

## 🎮 نحوه استفاده

بعد از اجرا، منوی زیبا ظاهر می‌شه:

1. Mandelbrot Set (کلاسیک و خفن)
2. Julia Set
3. Sierpinski Triangle
4. Barnsley Fern (سرخس طبیعی)
5. تولید انیمیشن زوم Mandelbrot
6. خروج

می‌تونی رزولوشن، تعداد تکرار و رنگ‌بندی رو تنظیم کنی.
